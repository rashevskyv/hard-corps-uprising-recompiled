# Hard Corps Uprising PC Recompilation

Experimental static recompilation project for the Xbox Live Arcade version of Hard Corps Uprising using ReXGlue.

## Status

Initial project setup.

## Game files

Original game files are not included and must be supplied by the user from a legally obtained copy.
